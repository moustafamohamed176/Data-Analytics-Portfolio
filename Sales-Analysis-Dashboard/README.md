Sales Analysis Dashboard
Project Overview

This project presents an interactive Sales Analysis Dashboard built using Microsoft Power BI.
The dashboard provides insights into customer sales performance, product revenue, and category trends to support data-driven business decisions.

Dashboard Preview




Key Insights

The dashboard highlights several important business metrics including:

Total Sales

Number of Customers

Number of Products

Additional analysis includes:

Average sales by product category

Sales rating distribution

Top 3 products by revenue

Bottom 3 products by revenue

Cumulative sales trends by delivery date

Cumulative sales trends by shipping date

Country-based filtering for regional analysis

Dashboard Features

Interactive filters based on Country

Dynamic charts and visualizations

Revenue comparison between products

Category performance analysis

Time-based sales trend analysis
